# ThaiNative: ภูติจิ๋วผจญภัย

หน้าแรกเป็นเดโม RPG จัดทีม 5 ตัวจากภูติ 6 ตัว แนวหน้า 2 แนวหลัง 3 ตัวละครโจมตีตามความเร็ว มีเกจสกิล 3 แต้ม ใช้สกิลเองหรืออัตโนมัติได้ มีเกราะ รักษา ดูดพลัง โจมตีเดี่ยวและหมู่ ปรับความเร็ว พัก และเริ่มใหม่ได้

เปิด `index.html` หรือรัน `python -m http.server 4173` แล้วเข้า http://localhost:4173

ตรวจระบบ RPG ด้วย `node battle-engine.test.js` เดโมนี้มีด่านเดียว ยังไม่มีบัญชี ออนไลน์ ระบบสะสมถาวร การอัปเกรด หรือการบันทึกทีม เมื่อรีเฟรชจะเริ่มใหม่ ภาพตัวละครเป็นภาพ 2D chibi ไม่ใช่โมเดล 3D

ภาพตัวละครสร้างด้วย image_gen ตามสไตล์อ้างอิงจากผู้ใช้ เก็บใน `assets/folklore-chibi-atlas.png` พรอมป์ต์อยู่ใน `assets/ART-PROMPT.md` ภูติ 6 ตัวใช้ภาพร่วมตามชนิด ตัวละครและพลังเป็นเรื่องแต่ง ฟอนต์ Google Fonts ใช้อินเทอร์เน็ตแต่มีฟอนต์สำรอง
